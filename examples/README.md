# 示例来源

`signals.fasta` 为合成序列，用于检查输入、末端基序和流程。

`yeast_reference.fasta` 与 `reference/` 保存公开酿酒酵母蛋白及注释，访问号为 [P00330](https://www.uniprot.org/uniprotkb/P00330/entry)、[P16474](https://www.uniprot.org/uniprotkb/P16474/entry) 和 [P19882](https://www.uniprot.org/uniprotkb/P19882/entry)。获取版本与注释记录在 JSON 中，遵循 [UniProt CC BY 4.0](https://www.uniprot.org/help/license)。

这些示例用于演示和流程核对，模型精度评估需要独立验证集。
